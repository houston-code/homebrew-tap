# Houston Homebrew tap

Homebrew formulae for [Houston](https://houstoncode.ai), a coding agent you run in your terminal. Bring your own model: Claude, GPT, Gemini, any OpenAI-compatible endpoint, or a local model.

```bash
brew install houston-code/tap/houston
houston --help
```

Upgrade with `brew upgrade houston`.

The formula installs the standalone CLI from the [Houston releases](https://github.com/houston-code/houston/releases) and depends on Homebrew's `node`. It is updated automatically when a new Houston release is published; please report problems in the [main repository](https://github.com/houston-code/houston/issues).
